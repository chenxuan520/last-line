# 胜利后返回大厅

## 目标

在单机胜利结算卡的“再来一局”旁增加“返回大厅”，同时保持联机结算动作不变。

## 验收

- 单机胜利且存在退出回调时显示“再来一局”和“返回大厅”。
- “再来一局”继续启动新的单机比赛。
- “返回大厅”复用会话退出回调并返回主菜单。
- 联机只显示既有“返回联机大厅”，不出现重复次按钮。
- 淘汰/观战控制和暂停卡不变。
- 聚焦测试、必要验证、浏览器检查和独立审查在提交前通过。

## 构建

- 先添加结果动作策略红测，再通过 `GameHud.options.onExit` 实现单机次级退出；聚焦测试 5/5 和完整 typecheck 通过。
- `GameHud.showResult` 保留“再来一局”为单机主动作，把 `onExit` 作为次级回调；联机只保留“返回联机大厅”主动作。
- 结果卡次级动作接口简化为固定“返回大厅”回调；淘汰卡复用同一路径。
- 架构文档同步记录单机/联机结果动作归属。
- 浏览器构建和预算在不改阈值下通过。
- 音量 `0` 的 production CSS 浏览器验收确认双列按钮布局正确，console 无应用错误；结束后返回 `about:blank` 并释放端口。

## 审查

- 独立审查按 `HEAD/main@f618ef9` 检查实现、测试、架构文档和本 plan，未发现 blocker、high、medium。
- 单机退出回调由 `BattleRoyaleSession` 传入 `GameApp.returnToMenu()`，先 dispose/清空活动会话再渲染主菜单。
- 联机结束仍只使用 `MultiplayerSession.onExit`，并由 dispose 关闭比赛连接。
- 聚焦测试直接执行单机/联机真实策略并校验回调身份；静态调用链和 production 浏览器证据覆盖 DOM 点击残余风险。
