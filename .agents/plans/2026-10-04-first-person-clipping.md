# First Person Clipping

## Goal

按用户明确选择的“镜头或枪械穿进墙里”及“自己在那个分支处理好”，在 `feat/ultra-town-visuals`／PR #9 修复第一人称贴墙表现。沿用已说明的镜头防穿、贴墙收枪和第一人称独立绘制方案。

## Context

- 基线 `3b45ace`，工作区干净；已检查用户澄清、工程指南、场景构建、单机／联机相机同步、换弹／跳跃姿态、权威移动与几何查询、测试及现有画面管线，分析超过 10 秒。
- 当前第一人称武器与世界共用深度，没有墙面距离查询；极高枪模还具有前向偏移。相机直接同步角色眼睛加视觉偏移，Babylon 的 `checkCollisions` 不会约束直接赋值或联机插值。

## Contract

- 单机与联机共享客户端第一人称处理，覆盖三地图及全部档位；使用现有权威地图几何查询，但只调整镜头、近裁剪面和手持模型表现。
- 不改变角色碰撞、权威位置、瞄准命令、伤害、弹道遮挡、协议、存档、地图生成、画质规格和资源预算。
- 镜头从权威眼睛向期望视觉位置做有界扫掠，防止跳跃／落地和联机修正进入障碍；近裁剪平面也要防止贴墙／抬头切开墙或天花板。
- 按当前武器真实模型范围查询附近障碍，贴墙平滑收枪；仅手持模型独立深度绘制，不改变地面物资和其他角色的遮挡。复用现有空间索引，不创建第二份地图或全场逐帧扫描。

## Plan

1. 补充能复现现有缺口的定向回归，实现共享第一人称防穿。
2. 覆盖墙角、门洞、低天花板、旋转墙、换枪／换弹／手雷／开镜与退出释放，逐个执行定向测试；完整 suite 和性能采样交给 CI。
3. 完成 typecheck、production 构建与原预算；已有 Chrome 和官方 MCP 静音验收桌面／触屏，Builder 与独立 Reviewer 亲自看图。
4. 同分支正常提交推送，完成精确 HEAD 的 CI、性能报告审查、Codex 与分支预览验收；不合并 PR 或提前部署生产 Worker。

## Build

- `FirstPersonPresentation` 在所有模型替换完成后创建，两种会话共用，缓存每种手持模型的局部范围；没有新增权威字段或服务端代码。镜头与武器复用现有环境扫掠，静止且没有视觉／插值偏移时不重复查询；固定非零偏移仍执行一次镜头位移扫掠，移动最多四次局部查询，不新增场景、相机、网格、材质或纹理。
- 5 个轻量定向用例分别通过：镜头视觉位移／跳跃约束和权威状态不变；宽屏低天花板完整近裁剪面；长短武器、开镜恢复与换弹；独立深度、无视觉偏移的静止零重复查询和原弹道遮挡；斜墙与开放门洞。真实场景另有 low／medium 岛屿、high 城镇、ultra 混合 4 个用例逐个通过，逐枪覆盖五种手持模型，地面物资仍在原深度组，资源数量不变。
- 初次短武器断言遇到 JavaScript 的 `-0`／`0` 精确值差异，改为数值近似比较；新整图城镇用例超过默认 5 秒，按既有整图用例设置本用例 60 秒超时，实测约 10 秒通过，不修改原性能门禁或既有用例。完整 suite 和性能采样未在本机执行。
- 全量 app／Worker／server typecheck、最终 production build、Worker dry-run 和 server build 通过。原 budget 通过：浏览器 JavaScript 4,090,695B／273 chunks，CSS 47,692B，dist 4,917,793B，Worker 634,872B，standalone 644,922B；预算没有放宽。
- 首轮已有 Chromium／官方 MCP 的静音 production 桌面与触屏检查通过真实状态切换及无异常 console。Builder 亲自看图发现下压幅度让贴墙武器落出屏幕，改为后收抬枪；继续看换弹图后，缩小抬枪和后收幅度，并减少与已有换弹抬枪的叠加，新增姿态组合断言通过。最终画面复核正在进行，不把早期截图当最终版本验收。
